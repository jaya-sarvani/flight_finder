# Flight Finder

Flight Finder is a simple flight booking web application developed as a student project. It allows users to search for available flights, view flight details, and book flights through an easy-to-use interface.

## Features

- User registration and login
- Search for flights
- View available flights
- View flight details
- Book flights
- View booking information
- Simple and user-friendly interface

## Technologies Used

### Frontend
- React.js
- Bootstrap
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/jaya-sarvani/flight_finder.git
```

### 2. Open the project

```bash
cd flight_finder
```

### 3. Install frontend dependencies

```bash
cd client
npm install
```

### 4. Start the frontend

```bash
npm start
```

### 5. Install backend dependencies

Open another terminal:

```bash
cd server
npm install
```

### 6. Start the backend

```bash
npm start
```

The application can then be accessed through the local development URL shown in the terminal.
